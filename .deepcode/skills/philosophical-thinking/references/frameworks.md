# 哲学框架速查卡

## 苏格拉底方法 (Socratic Method)
```
1. 提出一个定义/主张
2. 追问："这个定义能涵盖所有情况吗？"
3. 提出反例
4. 修正定义
5. 重复直到触及本质
```

## 第一性原理 (First Principles)
```
1. 列出所有假设
2. 对每个假设问："这一定为真吗？"
3. 剥离不确定的假设
4. 从剩余的基础事实重建推理
```

## 辩证法 (Dialectic)
```
正题 (Thesis) → 反题 (Antithesis) → 合题 (Synthesis)
合题成为新的正题 → 新的反题 → 更高的合题
```

## 亚里士多德四因说 (Four Causes)
```
质料因: 由什么构成？
形式因: 本质形式是什么？
动力因: 什么导致它产生？
目的因: 它的目的是什么？
```

## 斯多葛控制二分法 (Dichotomy of Control)
```
哪些在我完全控制范围内？ → 专注于这些
哪些不在我控制范围内？ → 接受这些
哪些部分可控？ → 专注于可控制的部分
```

## 康德的绝对命令 (Categorical Imperative)
```
1. 普遍化检验: 如果所有人都这样做，世界还能运转吗？
2. 目的公式: 我是否将人当作目的而非仅仅手段？
```

## 休谟断头台 (Hume's Guillotine)
```
不能从事实陈述（"是"）逻辑地推导出价值判断（"应该"）
→ 每次出现"应该"时，追问其前提中的价值假设
```

## 奥卡姆剃刀 (Occam's Razor)
```
在解释力相同的前提下，最简解释优先
→ 这个解释是否引入了不必要的实体？
```

## 波普尔证伪 (Popper's Falsification)
```
一个理论要成为科学，必须存在可以证伪它的条件
→ 这个论断在什么条件下会是错误的？
```

## 维特根斯坦的语言游戏 (Language Game)
```
词语的意义在于其使用
→ 这个词语在这个具体语境中是如何被使用的？
→ 我们是否在不同语言游戏之间混淆了？
```

## 道家无为 (Wu Wei)
```
不强行干预，顺应自然之势
→ 如果我们什么都不做，事情会自然演化成什么样？
→ 我们的"有为"是否在对抗自然的趋势？
```

## 禅宗公案思维 (Koan Thinking)
```
超越二元逻辑，直接把握整体
→ 放下"是/非"判断，整体感受这个情境
→ 语言的边界在哪里？边界之外是什么？
```

## 实用主义检验 (Pragmatic Test)
```
一个观念的意义在于其实践后果
→ 如果 A 为真，人们的行为会有什么不同？
→ 如果 B 为真，世界看起来会有什么不同？
```

## 存在主义视角
```
存在先于本质 — 人首先存在，然后定义自己
→ 在这个情境中，我/他人的根本自由是什么？
→ 这个选择是如何定义选择者自身的？
```
